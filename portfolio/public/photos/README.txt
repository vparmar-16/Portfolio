DROP YOUR PHOTOS IN THIS FOLDER
================================
Supported formats: .jpg  .jpeg  .png  .webp

Then in src/App.jsx, update each photo's src field:
  src: "/photos/your-filename.jpg"

Tips:
- Keep filenames simple, no spaces (use-dashes-instead.jpg)
- Resize large photos to max 2000px wide before uploading
  (speeds up the site a lot)
- portrait: true  → tall/vertical photo (2:3 ratio card)
- portrait: false → wide/horizontal photo (3:2 ratio card)
